# <span class="cat ongoing">Ongoing</span> How we test the objectives

1. **Distributed vs monolithic:** one $12$-qubit QCNN with the same encoding.
2. **Classical communication:** accuracy against no communication (NC); which Boolean function each trained message bit computes.
3. **Topology:** accuracy per transmitted bit for $1\to1$, $2\to1$ (default), $2\to2$ (to senders), $2\to3$ (broadcast).
4. **Open, bits vs qubits:** send the pooled qubits (QC) or only their outcomes (CC), at the same cost and location.
5. **Open, lottery tickets:** remove random message edges, retrain: can a sparser graph do better? (not run yet)

<div class="src">Frankle and Carbin, ICLR (2019).</div>

<!-- Speaker note: the objectives slide says what we want to know; this slide says how we test it. Items 1 to 3 test objectives 1 to 3; items 4 and 5 are open questions. Item 1: the monolithic QPU holds all 12 qubits with the same product-state encoding, one brick-wall circuit over all of them and pooling down to one 2-qubit readout (a standard QCNN). Item 2: each message bit is the threshold of a trainable decision function of two QPUs' estimated outcome probabilities; we compare the accuracy with no communication, read each trained decision function at the corners of the unit square to see which Boolean function it computes, and sweep its bias d. Item 3: the topologies 1 sender -> 1 receiver, 2 senders -> 1 receiver (default), 2 senders -> both senders, 2 senders -> all 3 QPUs (broadcast), all with three message bits per round, compared by accuracy per transmitted bit. Item 4: QC sends the pooled qubits to the neighbouring QPU; CC measures them mid-circuit and sends the single-shot outcomes, at the same communication cost and circuit location. First runs exist (five seeds) but are not settled and not shown today; more seeds and classical messages of increasing precision are planned. If asked: on contiguous blocks QC beats single-shot CC by only 0.8 +- 0.6 points (within noise); on permuted features by 2.4 +- 0.9 points. Item 5: remove random message edges of the communication graph, retrain, and ask whether a sparser graph sometimes does better, as "winning tickets" from magnitude pruning can in neural networks. -->
